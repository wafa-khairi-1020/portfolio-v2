# Wafa Khairi — Portfolio

A one-page personal portfolio site. Capstone for Sprint 1 of my web development course.

Built with HTML, CSS, and Bootstrap 5 (loaded from the CDN). No build step.

## How to view

Open `index.html` in a browser. Everything is self-contained — works locally or on any static host (GitHub Pages, Netlify, etc.).

## Folder structure

- `index.html` — the page
- `css/style.css` — custom styles
- `assets/` — wordmark and favicon (SVG)
- `images/` — project thumbnails
- `projects/` — every demo project, each in its own folder with an `index.html`
