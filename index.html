01 About

A short story.

I'm in my first year of web development. I like clean layouts, real content, and code I can read out loud. Right now I'm focused on the fundamentals — semantic HTML, mobile-first CSS, and the bits of Bootstrap that make responsive layout feel calm instead of fiddly.

Outside of class I read about design systems, sketch wireframes on paper before I open the editor, and try to write the kind of portfolio I'd want to read — short, honest, and easy to scan.

Long term, I want to work on small teams that care about the details: accessible defaults, typography that breathes, and pages that load fast on whatever device you happen to have.
